# tw-golden-cross-scanner

台股全市場（上市+上櫃，約2160檔）每日自動掃描，找出 MA5/MA20 黃金交叉、以及創新高/創新低的標的。全自動跑在 GitHub Actions，不需要本機開機，結果自動部署到 Vercel。

**線上網站**: https://tw-golden-cross-scanner.vercel.app/

## 運作方式

1. GitHub Actions 排程每天台北時間 17:45 觸發（收盤後、FinMind 資料更新後），也可以手動 `workflow_dispatch` 觸發。
2. `scan.js` 依 590次/小時的節流速度，跑完全市場約2160檔（約需1小時多）。每檔股票同時算：
   - MA5/MA20 是否發生黃金交叉
   - 是否創 1/3/6/12個月的收盤新高或新低（只標最長符合的區間，不含歷史全部新高/新低）
   - 前日收盤、今日收盤、漲跌幅、今日成交量、5日均量（不含今天）、成交量漲幅、是否量增（今日量 > 前5日均量1.3倍）
   - 每處理25檔就存檔並 commit+push 一次，避免中途被取消或超時而遺失進度；掃描過程中網站也會即時顯示進度與目前為止的結果。
3. 掃描完成後 `build_report.js` 整理出 base 清單（成交量>1000張 且 5日均量≥100張）、驗證前一交易日訊號的隔日表現，產生 `index.html`。

## 檔案說明

- `scan.js` — 全市場掃描主程式，含黃金交叉與創新高/創新低的判斷邏輯
- `build_report.js` — 掃描完成後整理報告、驗證前一交易日訊號、產生最終網頁
- `render.js` — 最終報告網頁的 HTML 產生器
- `render_progress.js` — 掃描進行中網頁的 HTML 產生器
- `state.json` — 當天掃描進度存檔（每天重置）
- `report.json` / `reports/YYYY-MM-DD.json` — 每天的報告存檔，供隔日驗證用
- `.github/workflows/daily-scan.yml` — 正式排程

## 篩選邏輯

- **黃金交叉 base 清單**：成交量 > 1000張 且 5日均量 ≥ 100張，依當日漲跌幅排序
- **創新高/創新低**：5日均量 ≥ 100張，只標最長符合的區間（1/3/6/12個月），不含全部歷史新高/新低
- **量增 highlight**：今日成交量 > 前5日均量（不含今天）的1.3倍，黃金交叉與創新高/創新低共用同一套規則
